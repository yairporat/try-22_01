# THV

## איך מריצים את הפרויקט

1. מתקינים [Node.js](https://nodejs.org) (גרסת LTS). צריך להתקין רק פעם אחת.
2. מורידים את הפרויקט: ב-GitHub עוברים לענף `claude/adventure-preview-tkdnrh`, לוחצים על **Code** ואז על **Download ZIP**, ומחלצים את הקובץ.
3. פותחים טרמינל בתוך התיקייה שחולצה ומריצים:
   ```
   npm install
   npm run dev
   ```
4. פותחים בדפדפן: http://localhost:3000

כדי לעצור את השרת: Ctrl+C בטרמינל.

## מה יש בפרויקט

```
data/
  places.xlsx          מאגר המקומות (אקסל): כאן מוסיפים ומעדכנים מקומות
  places.json          נוצר אוטומטית מהאקסל. לא לערוך ידנית
lib/
  adventure.js         ההתאמה: בוחר מקומות לפי האזור, המשך ורמת הקושי
app/
  layout.jsx           מעטפת לכל העמודים (עברית, מימין לשמאל)
  page.tsx             מסך הבית: "מצא לי את ההרפתקה שלי"
  adventure/page.jsx   עמוד ההרפתקה: התחנות, המפה, "התחל הרפתקה"
  adventure/go/        מסך הניווט: תחנה אחרי תחנה, אימות הגעה, דילוג וסיכום
  profile/page.jsx     פרופיל: הרשמה, מטבעות, סטטיסטיקות והרפתקאות שסיימתי
  map/page.jsx         המפה שלי: המקומות שהגעתי אליהם, עם פניקס על כל מקום ורשימה
components/
  AdventureMap.jsx     המפה (תחנות + המיקום שלך)
  StopDetails.jsx      פירוט תחנה שנבחרה במפה
public/places/         תמונות של המקומות
package.json           רשימת הספריות של הפרויקט
package-lock.json      הגרסאות המדויקות של הספריות
tsconfig.json          הגדרות TypeScript (בשביל page.tsx)
next-env.d.ts          קובץ ש-Next.js יוצר בעצמו
```

תיקיות שנוצרות לבד ולא צריך להעתיק: `node_modules` (נוצרת ב-`npm install`) ו-`.next` (נוצרת בהרצה).

## עדכון המקומות (`data/places.xlsx`)

כל המקומות נמצאים בקובץ האקסל `data/places.xlsx`, בגיליון "מקומות". כל שורה היא מקום אחד.
בגיליון "הוראות" יש הסבר על כל עמודה.

- **אזור, סוג, רמת קושי, מומלץ:** בוחרים מרשימה בתא.
- **מיקום בגוגל מפס:** פותחים את המקום בגוגל מפס > שיתוף > העתקת קישור, ומדביקים בתא. אפשר גם לכתוב שם מקום או כתובת.
- **תמונה:** מדביקים קישור לתמונה, או שמים את הקובץ בתיקייה `public/places/` וכותבים בתא רק את שם הקובץ, למשל `gamla.jpg`.

## חיבור ל-Google Sheets

אפשר לחבר את האפליקציה ישירות לטבלה ב-Google Sheets, וכך שינוי שנשמר בטבלה מופיע באפליקציה תוך כמה דקות, בלי להוריד קבצים.

1. מעלים את `data/places.xlsx` ל-Google Drive, פותחים אותו ובוחרים **קובץ > שמירה בתור Google Sheets**.
2. בטבלה החדשה: **קובץ > שיתוף > פרסום באינטרנט**. בוחרים את הגיליון **מקומות** ואת הפורמט **ערכים מופרדים בפסיקים (csv.)**, ולוחצים **פרסום**.
3. מעתיקים את הקישור שמתקבל ומדביקים אותו בקובץ `lib/config.js`, בשורה `PLACES_SHEET_CSV_URL`.

הקישור המפורסם מאפשר לכל מי שיש לו אותו לקרוא את הטבלה, אבל לא לערוך אותה.
אם הטבלה לא זמינה או שיש בה טעות, האפליקציה ממשיכה עם הרשימה האחרונה שעבדה, ובטרמינל מופיעה הודעה עם מספר השורה.

**כשלא מחוברת טבלה:** אחרי שמירת הקובץ מריצים `npm run dev` כרגיל, והמקומות נטענים לבד. אם יש טעות, למשל אזור שנכתב לא נכון או קואורדינטה חסרה, מופיעה הודעה עם מספר השורה באקסל.
אפשר גם לבדוק בלי להפעיל את האתר: `npm run import-places`.

הקובץ `data/places.json` נוצר מהאקסל בכל הפעלה, ולכן לא עורכים אותו ידנית.

### איך נבחרת ההרפתקה

- לוקחים את המקומות באזור שנבחר, ברמת הקושי שנבחרה או קלה ממנה (מעדיפים את הרמה שנבחרה).
- מוסיפים מקומות עד שנגמר הזמן: שעתיים = 120 דקות, חצי יום = 270, יום שלם = 480. בין תחנות מחשבים 25 דקות נסיעה. עד 5 תחנות.
- מסדרים את התחנות כך שכל תחנה היא הקרובה ביותר לקודמת.
- "הפתע אותי" בוחר אזור באקראי. הרפתקה מומלצת מתחילה במקום שנבחר.

את המספרים האלה אפשר לשנות בראש הקובץ `lib/adventure.js`.

## המפה ומסך הניווט

- **המפה** (OpenStreetMap, חינמית) מציגה את התחנות ואת המיקום שלך. לחיצה על תחנה מציגה זמן נסיעה, מרחק ופרטים.
- **זמני נסיעה** מחושבים לפי הכבישים (שירות OSRM החינמי). כשאין חיבור מוצגת הערכה, שמסומנת ב"כ-".
- **מסך הניווט** (אחרי "התחל הרפתקה"): ניווט ב-Google Maps או ב-Waze, חניה, ציוד מומלץ, חשוב לדעת ושעות פתיחה.
- **אימות הגעה:** "הגעתי" בודק שאתם במרחק של עד 400 מטר מהתחנה (אפשר לשנות ב-`ARRIVAL_METERS` בקובץ `app/adventure/go/page.jsx`). כשאין גישה למיקום אפשר לאשר ידנית.
- ההתקדמות נשמרת במכשיר, כך שאם סוגרים את האפליקציה באמצע, ממשיכים מאותה תחנה.

## דירוג הרפתקאות

בסוף כל הרפתקה אפשר לדרג אותה (1-5 כוכבים) ולכתוב הערות.

- **ברירת מחדל:** הדירוגים נשמרים בקובץ `data/feedback.json` במחשב שמריץ את האפליקציה.
- **שמירה ב-Google Sheets** (לשונית "דירוגים"): מתקינים את הסקריפט `scripts/google-apps-script.gs` (הוראות בראש הקובץ), ומדביקים את הכתובת שמתקבלת ב-`lib/config.js` בשורה `GOOGLE_SCRIPT_URL`.

## המפה שלי

הלשונית "מפה" במסך הבית מציגה את כל המקומות שהגעתם אליהם בהרפתקאות, עם פניקס על כל מקום, ורשימה של כולם עם תאריך הביקור.
מקום נכנס למפה ברגע שמאשרים הגעה אליו (תחנה שדילגתם עליה לא נכנסת). הרשימה נשמרת במכשיר.

## פרופיל ומטבעות

- **הרשמה:** בלשונית "פרופיל" נרשמים עם שם ואימייל. השם מופיע במסך הבית ("שלום, דנה!").
- **מטבעות:** מתחילים עם 100, ומקבלים 25 על כל הרפתקה שמסתיימת (אפשר לשנות ב-`ADVENTURE_REWARD` בקובץ `lib/profile.js`).
- הפרופיל והמטבעות נשמרים במכשיר. לחשבון אמיתי עם סיסמה, שעובר בין מכשירים, צריך לחבר שירות התחברות (למשל Supabase); כל הקוד של הפרופיל נמצא ב-`lib/profile.js` כדי שיהיה קל להחליף.

## נקודת יציאה וזמני נסיעה

- במסך הבית בוחרים "יוצאים מ:": המיקום הנוכחי (GPS) או עיר מהרשימה (`lib/origin.js`).
- ההרפתקה מתחילה בתחנה הקרובה לנקודת היציאה, ו"הפתע אותי" מעדיף אזורים קרובים.
- בעמוד ההרפתקה יש לוח זמנים: נסיעה לתחנה הראשונה, ביקורים, נסיעות בין התחנות וחזרה, עם סיכום ושעת חזרה משוערת. בסוף ההרפתקה יש כפתור ניווט חזרה.
- זמני הנסיעה מחושבים לפי הכבישים כשיש חיבור (OSRM), ואחרת לפי הערכה (`estimateDrive` בקובץ `lib/travel.js`).

## אימייל על כל הרשמה

כשמישהו נרשם, נשלח אליך אימייל עם השם והאימייל שלו, וההרשמה נשמרת בלשונית "נרשמים".
זה עובד דרך אותו סקריפט Google (`scripts/google-apps-script.gs`): מתקינים אותו פעם אחת ומדביקים את הכתובת ב-`lib/config.js` בשורה `GOOGLE_SCRIPT_URL`.
עד שהסקריפט מותקן, ההרשמות נשמרות בקובץ `data/signups.json`.

## התאמה לזמן שבחרו

ההרפתקה נבנית כך שתיכנס בזמן שבחרו (שעתיים / חצי יום / יום שלם) כולל הנסיעה הלוך וחזור.
אם אי אפשר, מופיעה הודעה עם המלצה לחלופה שכן נכנסת (אזור קרוב יותר או משך ארוך יותר), וכפתור "לבחור משהו אחר".

## הרפתקאות שבונים בעצמכם

בטבלה יש לשונית "הרפתקאות". כל שורה היא הרפתקה שלמה: שם, תיאור, ועד 5 תחנות שבוחרים מרשימת המקומות, לפי הסדר.
ההרפתקאות האלה מופיעות בדף הראשי ב"הרפתקאות מומלצות". האזור, המשך ורמת הקושי מחושבים מהמקומות.
"להציג בדף הראשי: לא" מסתיר הרפתקה בלי למחוק אותה. הנתונים נשמרים ב-`data/adventures.json` (נוצר מהטבלה).

## מצב הרפתקה, ביקורות ומייל סיכום (לפי ההנחיה)

- **מסך התוצאה** (`app/adventure/page.jsx`): תקציר קומפקטי – צ'יפים (זמן, אזור, קושי, מספר תחנות), מפה קטנה, רשימת תחנות קצרה, ו"יוצאים להרפתקה".
- **מצב הרפתקה** (`app/adventure/go/page.jsx`): משבצת לכל תחנה, "אתה כאן" על הנוכחית ו-✓ על שהושלמו. דף פרטים עם גלריית תמונות, הגעה ובטיחות וניווט. "אמת הגעה" רק בתחנה הנוכחית, לפי GPS ברדיוס של המקום (ברירת מחדל 400 מ'). כשאין הרשאת מיקום – אישור ידני, שמסומן בדוח. אחרי האימות: דירוג בפניקסים (אפשר לדלג) ומעבר אוטומטי לתחנה הבאה.
- **סיום**: רגיל, או מוקדם עם אישור וסיבה. נקודות רק כשמגיעים לכל התחנות. דירוג וביקורת סופיים.
- **מייל לבעלים** בסוף כל הרפתקה (`lib/email.js`, Resend): הדירוגים וההערות של כל תחנה, הדירוג הסופי, וסיבת סיום מוקדם. משתני סביבה: `RESEND_API_KEY`, `OWNER_EMAIL`. בלי מפתח – המייל נשמר בתיקייה `data/outbox`.
- **מסד נתונים**: `supabase/migrations/001_adventure_runs.sql` (places.gallery_images, adventure_runs, stop_reviews, RLS). משתני סביבה: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`. בלי Supabase – נשמר בקובץ `data/runs.json`.
- **בטבלה**: עמודות חדשות "תמונות נוספות" (גלריה) ו"רדיוס הגעה (מטרים)".

## מסך פתיחה, הישגים, מועדפים וגלריה (הנחיה 2)

- **מסך פתיחה** (`/welcome`): מי שעוד לא נרשם מגיע אליו לפני המסך הראשי. "בואו נתחיל" פותח את ההרשמה (מתחילים עם 100 מטבעות), ו"כבר יש לי חשבון" מתחבר לפי האימייל (`/api/login`). מי שרשום נכנס ישר למסך הראשי.
- **מסך ההרפתקה**: חזרה משמאל ולב (מועדפים) מימין, תמונה ראשית גדולה, שם ההרפתקה עם הדירוג הממוצע (פניקס), תיאור עם "קרא עוד", ושורת תמונות. לחיצה על תמונה פותחת **גלריה במסך מלא** שבה גוללים הצידה בין **כל** התמונות: של ההרפתקה, של כל תחנה, ושל "תמונות נוספות".
- **דירוג ציבורי**: הממוצע ומספר המדרגים גלויים לכולם (`/api/ratings`). הביקורות הכתובות נשלחות רק אליך.
- **מפות**: גוררים, מגדילים ומקטינים (גם בצביטה), "כל ההרפתקה" / "כל המפה" מראה את הכול, ו-⛶ פותח מסך מלא.
- **הישגים** בפרופיל: הרפתקה ראשונה, 5 מקומות, 3 אזורים. כל אחד מוסיף 50 מטבעות פעם אחת. הישג נעול מראה את ההתקדמות (למשל 2/5). עם Supabase הזיכוי נעשה בצד השרת (`supabase/migrations/002_profiles_achievements_ratings.sql`).
- **מועדפים**: הרפתקאות שסימנתם בלב מופיעות בפרופיל.
